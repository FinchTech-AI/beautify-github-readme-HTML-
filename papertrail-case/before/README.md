# PaperTrail

PaperTrail 是一个论文阅读助手的概念项目。它设想支持导入论文、整理阅读笔记和导出 Markdown。

## 功能

- 导入论文。
- 整理笔记，记录观点、证据位置和待核查问题。
- 导出 Markdown 文件。

## 使用流程

导入一篇论文，然后阅读并整理笔记，最后导出为 Markdown。笔记可以记录研究问题、核心观点、页码和需要继续核查的问题。

## 示例

研究问题：复习的时间安排会改变什么？证据定位：示例论文第 3 页。待核查问题：结论是否适用于不同任务和人群？这些文字是虚构示例，不是研究结论。

## 说明

本项目用于 README 设计演示，没有可运行的论文解析或 AI 服务，也没有安装包。目录中的示例 Markdown 可以直接阅读。请回到原文核查引用。
